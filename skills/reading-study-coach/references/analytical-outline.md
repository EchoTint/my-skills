# Analytical Structural Outline / 分析阅读式大纲

Use this reference when the user asks for analytical reading, deep breakdown, the author's problem, the book's structure, the book's argument, or a serious outline of a whole book.

The goal is not to copy the table of contents. The goal is to reconstruct the book's intellectual architecture: what problem governs the book, how the author divides that problem, why the parts come in this order, and how each part contributes to the whole.

## Core Distinction

### Inspectional Outline / 检视阅读大纲

Use for Quick Preview.

It answers:

- What does the book appear to be about?
- What visible parts does it have?
- Which parts should be read closely, skimmed, or skipped for now?
- What questions should move into analytical reading?

It may follow the table of contents, because it is only a first orientation.

### Analytical Structural Outline / 分析阅读式大纲

Use for Deep Breakdown.

It answers:

- What is the author's governing problem?
- How does the book's whole argument move?
- Why do the chapters belong in these functional groups?
- What task does each major part perform?
- How does each part prepare, transform, or complete the next part?

It must reorganize the table of contents into functional parts when the table of contents does not already reveal the book's argument.

## Required Output

When producing Rule 3 in analytical reading, include these elements unless the source is too short or the user explicitly asks for a brief answer.

### 1. Whole-Book Statement

Write one strong sentence that includes:

- Object / field: what the book studies.
- Governing problem: what question drives the book.
- Main answer or direction: what the author seems to argue.
- Development path: how the book moves from beginning to end.

The sentence should be precise enough that a later rereading could prove it wrong.

### 2. Governing Question

State the core question in question form.

Good governing questions are not topics:

- Weak: "This book is about automation."
- Strong: "When machines can communicate, learn, and control, how can human beings prevent social systems from treating people as replaceable machine parts?"

### 3. Whole-Book Movement Formula

Compress the structure into a movement line.

Examples:

- `Problem -> Method -> Concepts -> Applications -> Consequences`
- `Historical crisis -> Conceptual framework -> Institutional analysis -> Practical judgment`
- `Control theory -> Life and language -> Social institutions -> Automation -> Human value`

This formula is not a decoration. It should explain why the book's parts come in this order.

### 4. Functional Major Parts

Group chapters or sections into 3-6 major functional parts.

For each major part, provide:

| Major Part | Chapters / Sections | Function In The Whole | Why These Chapters Belong Together | Transition From / To Other Parts | Evidence |
|---|---|---|---|---|---|

The "function" column should use verbs such as:

- establishes the problem
- builds the conceptual frame
- defines the key distinction
- extends the theory to a new domain
- tests the theory against cases
- answers an objection
- shifts from explanation to evaluation
- draws practical consequences

Avoid vague functions such as "talks about X" or "introduces Y" unless followed by why that move matters.

### 5. Chapter Function Table

After the major-part outline, give a chapter-level table:

| Chapter / Section | Local Question | Local Function | Contribution To Whole Argument | Evidence / Confidence |
|---|---|---|---|---|

The chapter table should explain the role of each chapter, not merely summarize its topic.

### 6. Connection Explanation

Add a short prose explanation of how the whole book advances.

Use this pattern when helpful:

1. First the author must show...
2. Then the author can argue...
3. This allows the author to move from...
4. The later part matters because...
5. The whole book finally returns to...

### 7. Construction Note

Briefly explain how the outline was inferred:

- title / subtitle
- preface / introduction
- table of contents
- chapter titles
- opening and closing chapters
- recurring concepts
- sampled passages
- external bibliographic or known context, if used

This helps the user distinguish textual evidence from reader reconstruction.

### 8. Evidence Status

For weak, scanned, or partial sources, label each claim:

- **Confirmed**: supported by extracted text, page image, table of contents, bookmarks, or quoted passage.
- **Reasoned inference**: inferred from title, subtitle, chapter sequence, known edition information, or visible structure.
- **Needs OCR / rereading**: requires page-level text before final judgment.

Do not let missing OCR collapse the outline into a shallow table. Build the best provisional structure available, while clearly marking uncertainty.

## Quality Gate

Rewrite the outline if any of these are true:

- It is only a copied table of contents.
- It only summarizes chapters one by one.
- It lacks a governing question.
- It lacks a whole-book movement formula.
- Major parts are grouped only by adjacency, not by function.
- It does not explain why chapters belong together.
- It does not explain transitions between parts.
- It says what chapters discuss but not what they do in the argument.
- It does not separate confirmed evidence from inference when the source is incomplete.
