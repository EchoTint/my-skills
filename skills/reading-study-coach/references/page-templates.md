# Reading Wiki Page Templates

Adapt labels to the user's language and actual genre. These are note shapes,
not required empty scaffolds. Preserve existing notes; record unknowns explicitly.
Use actual locators and correct relative links. For identity, assessment evidence,
objective ownership, and review state use [wiki-state.md](wiki-state.md).

## Concept Page

```markdown
# Concept Name
- Source/version/unit:
- Objective owner/status: Untested or a link to actual assessment evidence

## Source Meaning
Paraphrased author definition, with its conditions and locator.

## Plain-Language Explanation
User-authored explanation, or clearly labeled assistant proposal.

## My Understanding
Actual user reconstruction; awaiting user input if not supplied.

## Evidence And Boundaries
Supporting examples, counterexamples, neighboring concepts, and uncertainty.

## Application
Proposed use versus independently verified practice, clearly separated.

## Related
Equivalent / complementary / conflicting / prerequisite links.
```

## Case Page

```markdown
# Case Title
- Source/version/unit:

## What Happened
Concise source-backed retelling or observed result.

## What It Supports
Specific claim supported; do not relabel anecdote as proof.

## Limits And Credibility
Sample/design/replication where relevant, alternatives, scope of inference.

## Related
Links to the relevant concept/model/question.
```

## Model Page

```markdown
# Model Or Framework
- Source/version/unit:

## Problem And Mechanism
The problem addressed, elements, steps, or causal/argument structure.

## When To Use
Prerequisites and appropriate contexts.

## When Not To Use
Counterexamples, assumptions, failure conditions, and misuse risks.

## My Understanding And Practice
User explanation and actual evidence, not an invented personal reflection.

## Other Models
Complementary or competing models, preserving differences in conditions.
```

## Chapter Or Reading-Unit Note

```markdown
# Unit Title
- Source/version:
- Actual read scope:
- Access/extraction gaps:
- Guiding question:

## Function In The Whole
What this unit does, not merely its table-of-contents title.

## Source Content
Local argument/definitions/evidence, or narrative/form/imagery for literature.

## Connections
Previous/next unit dependencies and related topic questions.

## My Takeaway
User-supplied understanding; label assistant candidates separately.

## Pending Checks
Unproven objectives, open questions, and deferred reading.
```

## Question Page

```markdown
# Question
- Origin/source scope:
- Status: Open / Partially Resolved / Resolved

## My Thinking
Actual user hypothesis, if provided.

## Answers And Evidence
Source-backed positions versus inference; inaccessible/unread is not silence.

## Resolution Or Next Step
What changed the status, or which evidence/read/practice is still needed.
```

## Quote Page

```markdown
# Short Quote
> Verified short original excerpt

- Source/version/unit/locator:
- Context:
- Why It Matters: user's reflection or awaiting input
- Related:
```

Do not invent quotations from memory or substitute an assistant paraphrase inside
quotation marks. Preserve page/section references only when actually verified.

## Cross-Source Concept Page

```markdown
# Shared Concept Or Question

## Working Vocabulary
Neutral working meaning; author-specific terms and translation risks.

## Perspectives And Conditions
Each source's claim, locator, assumptions, and relation to other positions.

## Evidence And Discussion
Independent support, disagreements, indirect answers, and unanswered gaps.

## User Synthesis
Actual user conclusion, or assistant synthesis labeled as provisional.

## Canonical Learning Objective
Link to one owner and its evidence/review schedule; no duplicate mastery claim.
```

## Practice And Session Notes

Practice: objective, success criteria, unfamiliar condition, user artifact/result,
assistance used, verification performed, error/boundary, outcome, and next step.
Session: goal/unit, real user progress, corrected misconception, still-unproven
objectives, due/deferred work, and resume action. Record learning delta, not the
full transcript. See [practice-loop.md](practice-loop.md) for the execution boundary.
